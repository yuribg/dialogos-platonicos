# dialogos-platonicos
Repositório de Diálogos Platônicos

Coleção de diálogos de Platão em domínio público, organizada para leitura e download.

Os textos de referência em inglês foram obtidos a partir do MIT Classics / Internet Classics Archive, disponível em [MIT Classics](https://classics.mit.edu/).

Desenvolvido em português-BR por Yuri Galli.
